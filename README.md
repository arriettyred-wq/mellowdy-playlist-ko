# Mellowdy: Playlist Ko!

Spotify-inspired music and podcast player built for the Extension Project.

## Live demo
https://arriettyred-wq.github.io/mellowdy-playlist-ko/

## Features
- Sidebar with Home, Search, Library, playlists and school logo
- Hero banner with a greeting based on the time of day
- Cards for Recently played, Top hits and Featured podcasts
- Player bar with play/pause, previous, next, shuffle, loop,
  progress bar and volume/mute
- Full-screen now playing view with a spinning vinyl and lyrics
- Real-time search and 3 background themes
- Responsive for desktop, tablet and mobile

## Built with
HTML, CSS (Grid and Flexbox) and JavaScript
